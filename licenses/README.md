# License records

Kept as proof of each third-party license (see the SauceStore content policy).

- `CC0-1.0.txt`: the CC0 1.0 Universal legal code. Every third-party model, sound and music track in this game is CC0. `CREDITS.md` lists each one with its author and source URL.
- Kenney packs: each `assets/packs/kenney_*/License.txt` is Kenney's own CC0 statement.
- `godot-LICENSE.txt` and `godot-COPYRIGHT-third-party.txt`: the Godot Engine MIT license and its third-party notices. They're required because the Windows build embeds the Godot runtime, and they ship inside the release zip.
